Understand the workload first

Infrastructure decisions should start with users, applications, data, access and recovery requirements.

  • Dedicated environments where appropriate
  • Server administration and access management
  • Backup design and recovery planning
  • Monitoring requirements and escalation
02

Make responsibilities explicit

A service is easier to manage when everyone knows what is included and who responds.

  • Workload and dependency inventory
  • Availability and recovery objectives
  • Security responsibilities and change control
  • A scoped proposal with support boundaries
