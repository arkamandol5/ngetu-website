Start with the decision, then connect the data.

Agree the definition

The same word can mean different things across teams. Establish the source, calculation, owner and refresh timing for each measure.

  • Choose a small set of business questions
  • Check permission to access each source
  • Resolve missing or duplicate records
02

Build a view people can use

Start with a safe sample and test the questions with the people making the decisions.

  • Show freshness and limitations
  • Drill into the reason behind a change
  • Review whether the report led to useful action
